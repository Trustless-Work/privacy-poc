# Demo app

The Next.js demo will adapt the reference app into five task-oriented views:

- payer: register, deposit USDC, merge, create escrow, and fund allowance;
- receiver: register, inspect status, recover incoming balance, and disclose payment;
- approver: approve the configured milestone;
- release signer: submit the bound confidential release;
- auditor: decrypt covered amounts without spending authority.

The app must visibly label the network, underlying asset, wrapper contract, and test-only status.
