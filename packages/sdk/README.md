# SDK package

Extends the reference `@ctd/sdk` with Trustless Work escrow helpers.

Planned modules:

- upstream confidential crypto, witness, proving, chain, state, auditor, and disclosure modules;
- USDC base-unit conversion and runtime decimal assertions;
- milestone commitment construction;
- proof-bound escrow release inputs;
- escrow transaction builders;
- indexed state recovery and commitment verification.

Private openings and keys must never be logged or sent to analytics.
